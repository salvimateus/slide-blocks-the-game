# Primitives

- One inventory for the whole project, at the project root.
- The project uses no `class_name`: each name below is the `preload` constant or the autoload name that the code uses.
- Status is `confirmed` (implementation read) or `inferred` (only references seen); `pending <branch>` marks code that the integration branch `main` does not have yet, and a bare `pending` marks code that is not in a commit yet.

## core

- **`Level`**, `scripts/core/level.gd`, confirmed
  The parsed map of one level as flat arrays by cell, shared by the rules, the solver and the views. Contract: `id`, `index`, `name_key`, `hint_key`, `cols`, `rows`, `cells`; by cell `floor_cells`, `obstacle`, `deflector` (`NONE`, `NW`, `NE`, `SW`, `SE`) and `floor_bit` (paint bit, -1 off the floor); `starts` (start cell of each block, index = block id - 1), `floor_count`, `step` (cell offset for U, D, L, R), `errors`, `is_valid()`, `col_of(cell)`, `row_of(cell)`. The level definitions live in `scripts/core/levels_data.gd` (`LEVELS`); `name_key` and `hint_key` are keys of [[PRIMITIVES#Strings]].
  Consumers: >=7 (LevelParser, SlideRules, Solver, Session and level_thumb preload it; BoardView and SwipePlayer read its fields).
- **`LevelParser`**, `scripts/core/level_parser.gd`, confirmed
  Turns one map definition (rows of glyphs) into a validated Level. Contract: `static parse(def: Dictionary, index: int) -> Level`; it never fails hard, each problem goes to `Level.errors` as `row R col C: message`, counted from 1. Glyphs: `#` void, `X` obstacle, `.` floor, `1` to `9` block start on floor, `┌┐└┘` deflectors NW, NE, SW, SE on floor. It rejects floor on the border, a floor that is not connected, a deflector with floor on a closed side or no floor on an open side, a block on a deflector, and block ids that are not 1..n. The limits `MAX_FLOOR` 62, `MAX_CELLS` 255 and `MAX_BLOCKS` 4 come from the state packing of [[PRIMITIVES#Solver]]; raise them only with a Solver change.
  Consumers: >=6 (Game, board_lab, ui_lab, demo_board, level_thumb, tools/levels_tool.gd).
- **`SlideRules`**, `scripts/core/slide_rules.gd`, confirmed
  The one movement rule: all blocks slide in one direction, one cell for each tick, until each block stops. Contract: directions `UP` 0, `DOWN` 1, `LEFT` 2, `RIGHT` 3, `DIR_CHARS` "UDLR", `dir_from_char(c)`; `static resolve(level, pos, dir, out, events = null) -> int` writes the end cells to `out` and returns the mask of the floor bits that the blocks entered (the start cells are not in it); with an `events` Array it appends `step` events (`tick`, `block`, `from`, `to`, `dir`, `turned`) and `stop` events (`tick`, `block`, `cell`, `dir`, `cause` wall, block or loop, `travelled`) in tick order. A block on a deflector cell turns before its next step; when two blocks aim at one cell, the lower block id moves; a repeat of (block, cell, dir) stops the block with cause `loop`. SwipeInput, BoardView, BlockView, FxPool and Harness use the same direction order.
  Consumers: >=4 (Session, Solver, demo_board, board_lab); SwipePlayer reads its events through the Session outcome.
- **`Solver`**, `scripts/core/solver.gd`, confirmed
  Exact breadth-first search for the minimum move count of a level, for offline use only. Contract: `static solve(level, cap = 3000000) -> {min, solution, states}`, or `{}` when the level has no solution or the search passes the cap; `static has_dead_end(level)` (a reachable position set that cannot return to the start); `static has_loop(level)` (a lone block on a deflector hits the loop guard); `static pack(pos) -> int` (8 bits for each block). A move counts only when the end positions differ from the start positions, the same rule as Session. The game never solves at runtime: `tools/levels_tool.gd -- --write` writes `scripts/core/par_data.gd` (`PAR[id]` with `min` and `solution`) and `-- --check` verifies it, so a level change needs a new par write.
  Consumers: >=1 (tools/levels_tool.gd); the ParData readers are Game, Harness, demo_board, board_lab and ui_lab.
- **`ScoreRules`**, `scripts/core/score_rules.gd`, confirmed
  The star ranges, the move limit and the tension point of a level, from its minimum move count. Contract: `static thresholds(min_moves, index) -> {min, three_max, two_max, limit, tension_moves}`, `static stars_for(moves, t) -> 0..3`, `static range_for(stars, t) -> Vector2i(lo, hi)` (stars 0 gives the moves above the limit), `static is_tense(moves_used, t)`. The limit factor becomes smaller as the level index increases, so each caller must give the real level index.
  Consumers: >=4 (Session, Game, ui_lab, tools/levels_tool.gd); RangeBar reads the thresholds dictionary.
- **`Session`**, `scripts/core/session.gd`, confirmed
  The rule state of one level attempt: positions, paint, moves, status and tension. Contract: `Session.new(level, min_moves, hues)` with `min_moves` from ParData ([[PRIMITIVES#Solver]]) and `hues` from [[PRIMITIVES#Palette]]; `swipe(dir) -> outcome` with `ignored`, `dir`, `moved`, `counted`, `events`, `paints` (`tick`, `block`, `cell`, `hue`, `fresh`), `positions`, `ticks`, `status`, `moves_used`, `stars`, `tense`, `tense_changed`, `tier_dropped`, `last_cell`; `snapshot() -> Dictionary`, `is_complete()`, `stars()`; `status` is `ready`, `playing`, `won` or `lost`. The state changes at once in `swipe` and the views replay the outcome after it ([[PRIMITIVES#SwipePlayer]]). A swipe that moves no block does not count, a level complete on the limit move is a win, and a repaint gives the cell the color of the last block.
  Consumers: >=3 (Game, demo_board, board_lab); Harness reads `snapshot()` through `Game.snapshot()`.
- **`Palette`**, `scripts/core/palette.gd`, confirmed
  The color source of the game: four reference colors, the derived colors and the eight block color families. Contract: named `Color` constants; `PAINT`, `BODY` and `OUTLINE` indexed by palette index 0..7 (`FAMILY_SIZE`); `static pick_block_hues(count, rng) -> PackedInt32Array` of palette indices (a random start k, then k, k+2, k+4, k+6 in a shuffled order, and the odd offsets after four blocks). A block `hue` in the code is a palette index, not a degree; `HUES` holds the degrees only as a reference.
  Consumers: >=17 (Game, board_lab, ui_lab, background, BoardView, ceremonies, demo_board, FxPool, SwipePlayer, TextureBank, Icon, JuicyButton, level_thumb, RangeBar, Screen, switch, UiTheme).

## runtime

- **`Bus`**, `autoload/bus.gd`, confirmed
  The global signal hub between game flow, board, audio, UI and harness. Contract: signals only, declared in `autoload/bus.gd`; each listener connects by itself. Game emits the level flow signals at rule time, directly after `Session.swipe`; [[PRIMITIVES#SwipePlayer]] emits the swipe signals at visual time; `scripts/board/ceremonies.gd` emits the `ceremony_*` signals. Code that must follow the screen (sounds, harness marks) listens to the visual-time signals; code that needs the rule state listens to `session_changed`.
  Consumers: >=14 (Game, Harness, Music, Save, Sfx, ui_lab, ceremonies, SwipePlayer, defeat_card, hud, JuicyButton, level_card, pause_dialog, result_card).
- **`Tuning`**, `autoload/tuning.gd`, confirmed
  The home of the tuning knobs: global knobs in the autoload and one constants file for each domain. Contract: constants only; `Tuning.Board`, `Tuning.Audio` and `Tuning.Ui` preload `scripts/board/board_tuning.gd`, `scripts/audio/audio_tuning.gd` and `scripts/ui/ui_tuning.gd`, and most scripts preload these files directly as `BoardTuning`, `AudioTuning` and `UiTuning`. Board knobs are in board units (one atlas texel); BoardView scales them into the fit rect.
  Consumers: autoload >=7 (Feel, Game, BoardView, SwipeInput, card_screen, column, pause_dialog); BoardTuning >=7 (BlockView, BoardView, ceremonies, demo_board, FxPool, SwipePlayer, TextureBank); AudioTuning >=3 (Music, Sfx, AudioBank); UiTuning >=8 (Game, ui_lab, column, JuicyButton, RangeBar, Screen, switch, UiTheme).
- **`Feel`**, `autoload/feel.gd`, confirmed
  Hit-stop, haptics and the reduced-motion scale in one place. Contract: `hit_stop(ms)` (lowers `Engine.time_scale` for real milliseconds scaled by `motion()`; a new hit-stop replaces the end time), `set_base_time_scale(scale)` (used by the harness `--time-scale`), `vibrate(kind)` with a key of `Tuning.HAPTIC_MS` (mobile only, with the `haptics` setting), `motion() -> float` (1.0, or `Tuning.REDUCED_MOTION_SCALE` with the `reduced_motion` setting). Change `Engine.time_scale` only through Feel; a tween that must keep real time needs `set_ignore_time_scale(true)`, as in Music. Scale each motion amount and particle count by `motion()`.
  Consumers: >=15 (Harness, BlockView, BoardView, ceremonies, FxPool, SwipePlayer, card_screen, defeat_card, home_screen, hud, JuicyButton, level_select_screen, pause_dialog, Screen, switch).

## board view

- **`TextureBank`**, `scripts/board/texture_bank.gd`, confirmed
  Bakes every board visual one time into one atlas texture and serves its regions. Contract: add an instance to the tree and `await bank.bake()` (signal `baked`; Game.boot does it before it makes a view), then the static getters `tex(key)`, `paint_tile(hue)`, `block(hue)`, `particle(key)`, `glitter(hue)`, `pattern()`, `soft()`, `is_baked()`. The region names are in `BIG_ROW_0`, `BIG_ROW_1` and `SMALL_NAMES`, and the inner `Painter` draws them. CPUParticles2D cannot draw an atlas region, so a particle texture must also be in `STANDALONE` and be read with `particle()`. A headless run stores a white placeholder atlas.
  Consumers: >=6 (Game, board_lab, background, BlockView, BoardView, FxPool).
- **`FxPool`**, `scripts/board/fx_pool.gd`, confirmed
  Pooled one-shot CPUParticles2D emitters of one board, so an effect never allocates during play. Contract: `attach(under, over, glow)` one time (BoardView.build calls it); `splash(pos, dir, color, tiles)`, `impact_ring(pos, color, power)`, `rail_spark(pos)`, `ring_glitter(points, hue) -> count`, `burst(center, hues)`, `streak(block)`, `streak_on(block, on)`, `set_streak_color(block, color)`, `set_board_scale(s)`, `clear()`; static `set_particles_enabled(on)` and `set_glow_enabled(on)` act on every pool. Counts scale with `Feel.motion()`. It holds one streak for each block up to `MAX_BLOCKS` 4, the same limit as `LevelParser.MAX_BLOCKS`.
  Consumers: >=4 (BoardView owns it; Game uses the static switches for the PerfPanel options; SwipePlayer and ceremonies call it through `board.fx`).
- **`BlockView`**, `scripts/board/block_view.gd`, confirmed
  One jelly block on screen (shadow, body, eyes), with every block motion as native tweens. Contract: `setup(hue, seed)`, `set_hue(hue)`, `set_mood(&"open" | &"happy" | &"sad")`, `look(dir)`, `start_motion(dir)`, `turn_motion(new_dir, time)`, `squash(dir, amount)` (the jelly squash with the contact edge fixed on the wall), `jiggle(dir, power)`, `nudge(dir)`, `squint()`, `hop(height, time, delay)`, `drop_in(height, time, delay, on_land)`, `hop_to(target, time, delay, new_hue, on_land)`, `deflate()`, `deflate_now()`, `flash_white()`, `reset_pose()`, `settle()`; fields `hue` and `mood`. Its `position` is the cell center and belongs to the caller; the inner nodes (bob, jelly pivot) carry the juice, so a squash or a hop never moves the cell position.
  Consumers: >=3 (BoardView makes it; SwipePlayer and ceremonies drive it through `board.blocks`).
- **`BoardView`**, `scripts/board/board_view.gd`, confirmed
  The node that draws one level (tray, tiles, rails, obstacles, blocks) with the board juice, reused for every level. Contract: `build(level, hues)` after the TextureBank bake, `fit(rect)`, `content_size()`, `cell_pos(cell)` (board units), `cell_global(cell)`, `board_rect_global()`, `floor_cells()`; tile calls `set_tile_paint`, `paint_tile(cell, hue, fresh)`, `tile_flash`, `tile_jump`, `tile_crossfade`, `tile_pulse`, `rail_pop`; `kick(dir, tiles)`, `pulse()`, `nudge(dir)`, `show_scrim(on)`, `set_scrim_now(on)`, `settle()`; `play_intro()` (signal `intro_finished`), `play_restart(hues)` (signal `restart_finished`), `reset(hues)`; `rings_from(cell)`, `rings_from_edge()`, `ring_points(ring)`; fields `level`, `hues`, `paint_hue` (-1 none, `GRAY` -2, else a palette index), `blocks`, `player` (SwipePlayer), `ceremonies`, `fx` (FxPool). `paint_hue` follows the playback, not Session, so during a swipe it can be behind the rule state.
  Consumers: >=3 (Game, demo_board, board_lab); SwipePlayer and `scripts/board/ceremonies.gd` drive it through their `board` field.
- **`SwipePlayer`**, `scripts/board/swipe_player.gd`, confirmed
  Replays one Session outcome on its BoardView and emits the swipe Bus signals at visual time. Contract: `play(outcome)` (a moved outcome slides the blocks; `moved` false plays the nudge and emits `swipe_ignored`), `stop()` (ends at the final state with no signal), `duration(outcome)`, `is_playing()`, `speed_scale` (Game sets `BoardTuning.BUFFERED_SPEED` while a swipe waits in the buffer), signal `finished(outcome)` (also for an ignored outcome); `emit_bus` and `use_feel` are false for the demo board. One tick lasts `BoardTuning.STEP_TIME`, a tile gets its paint at `PAINT_AT` of its tick, and a step into and out of a deflector plays as one arc. It is the only source of `swipe_started`, `tile_painted` (step = tick - 1), `block_turned`, `block_stopped` (power from the travelled tiles), `swipe_finished` and `swipe_ignored`.
  Consumers: >=4 (BoardView owns it as `player`; Game, demo_board and board_lab call `play`).

## audio

- **`AudioBank`**, `scripts/audio/audio_bank.gd`, confirmed
  The table of every audio stream, the shared stream cache and the bus layout. Contract: tables `SFX` (key to `path`, `base_hz`, `db`) and `MUSIC` (key to `path`, `bpm`, `bars`, `frames`); `SFX_BUS`, `MUSIC_BUS`; static `ensure_buses()` (SFX and Music buses, master hard limiter, Music low-pass filter; safe to call again), `load_table(table)`, `stream(key)`, `volume_db(key)`, `missing()`, `loop_seconds(clip)`, `is_dummy_driver()`, `music_filter()`. A stream loads only when `ResourceLoader.exists()` is true, so a file that is not baked goes to `missing()` and causes no error. `MUSIC[clip].frames` must equal the loop length that `tools/bake_audio.gd` writes from `tools/audio/score.gd`; the tempo and the bar count are also in `AudioTuning` and in the score, and `bake_audio -- --check` compares the files only with the score, so change all three together.
  Consumers: >=2 (Sfx, Music).
- **`Sfx`**, `autoload/sfx.gd`, confirmed
  Plays every sound effect from one polyphonic player on the SFX bus. Contract: `play(sound, pitch = 1.0, volume_db = 0.0)` with a key of `AudioBank.SFX`, `note(sound, step)` on the `paint`, `ring` or `star` note ladder of `AudioTuning`, `warm_up()`, `silence()`, `missing()`. It connects to the Bus by itself and Game is its only direct caller, so a sound for a game event is a Bus handler here. It is silent on the Dummy driver, `--audio-log` prints each play, and the `sfx` setting mutes its bus.
  Consumers: >=1 (Game calls `warm_up`, `missing` and `silence`); all other triggers come through Bus.
- **`Music`**, `autoload/music.gd`, confirmed
  The calm and tense music loops, with the beat clock, the fill filter, the duck and the defeat tape stop. Contract: `start()`, `stop()`, `set_tense(on)` (the change starts on the next beat of the clip that plays), `set_fill(ratio)` (low-pass cutoff from the painted share), `duck(db, seconds)`, `unduck(seconds)`, `tape_stop(seconds)`, `state() -> {playing, clip, bpm, cutoff_hz, beat}`; it emits `Bus.music_beat(index, tense)` and connects by itself to the Bus tension, session, ceremony, level, pause and setting signals. On the Dummy driver, or when a stream is absent, a virtual clock follows the frame clock, so the beat and `state()` also work in scripted runs. Its tweens ignore `Engine.time_scale`, so a hit-stop does not bend the music.
  Consumers: >=2 (Game calls `start`, `stop`, `unduck` and `set_fill`; Harness reads `state()`).
- **`Synth`**, `tools/audio/synth.gd`, confirmed
  The offline DSP vocabulary of the audio bake; it never runs in the game. Contract: static functions on mono `PackedFloat32Array` buffers at `SR` 44,100 Hz, which change the buffer in place and also return it: sources, envelopes, filters, a Schroeder reverb, a ping-pong echo, mix with equal-power pan, loop fold, measures, `count(seconds)`, `hz(midi)` and `to_stream(left, right) -> AudioStreamWAV` (16-bit; an empty right buffer gives mono). The output of `warm_osc` does not start at zero, so always apply `fade_in` to it.
  Consumers: >=1 (tools/bake_audio.gd).

## input

- **`SwipeInput`**, `scripts/input/swipe_input.gd`, confirmed
  Turns the first finger of a touch into one swipe or one tap at most. Contract: signals `swiped(dir)` (SlideRules direction order) and `tapped`; `enabled` (false also drops the touch in progress); `static direction_of(delta, threshold) -> dir or -1`; thresholds `Tuning.SWIPE_THRESHOLD` and `Tuning.TAP_SLOP`. It reads `_unhandled_input`, so a touch that a Control takes (a button) is never a swipe. Keyboard swipes do not go through it: Game maps the actions `swipe_up`, `swipe_down`, `swipe_left` and `swipe_right` to `request_swipe` itself.
  Consumers: >=1 (Game connects `swiped` to `request_swipe` and `tapped` to the ceremony skip).

## ui

- **`Strings`**, `scripts/ui/strings.gd`, confirmed
  The one table of UI text, in pt-BR. Contract: `static t(key, vars = {}) -> String` with `{name}` placeholders (String.format); a missing key returns the key itself and pushes a warning.
  Consumers: >=12 (Game, PerfPanel, level_card, RangeBar, Screen and tools/load_all.gd preload it; home_screen, level_select_screen, hud, pause_dialog, result_card and defeat_card use it through Screen).
- **`UiTheme`**, `scripts/ui/ui_theme.gd`, confirmed
  Fonts, the one Theme and the style helpers of the UI code. Contract: `static font(weight) -> FontVariation` (Nunito; the raw FontFile opens at weight 200, so always use this call), `build() -> Theme` (Game sets it on the root window at boot), `box(color, radius, border_color, border, lip, lip_color)`, `card_box(radius)`, `pad(sb, horizontal, vertical)`, `label(text, size, weight, color, align)`, `style_label`, `paragraph`, `vbox`, `hbox`, `panel`, `spacer`, `time_text(ms, template)`, `safe_insets(node)` (notch and system bars, mobile only); meter colors `ZONE_THREE`, `ZONE_TWO`, `ZONE_ONE`.
  Consumers: >=16 (Game, ui_lab, Screen, card_screen, column, defeat_card, home_screen, hud, JuicyButton, level_card, level_select_screen, pause_dialog, RangeBar, result_card, switch, toggle_row).
- **`Screen`**, `scripts/ui/screen.gd`, confirmed
  The base of every full-screen UI layer, with one open and close motion. Contract: `open(data = {})`, `close()`, `is_open`, signals `opened` (motion at rest) and `closed` (hidden); a subclass makes its children in `_init`, fills the data in `_fill(data)` and can replace `_play_in()`; the helpers `_button(kind, text_key, icon_kind, height)` and `_round_button(icon_kind)` make JuicyButtons with Strings text. It preloads Palette, Strings, UiTheme, UiTuning, Icon, JuicyButton and Column for its subclasses.
  Consumers: >=7 (home_screen, level_select_screen, hud, pause_dialog and card_screen extend it; result_card and defeat_card extend card_screen).
- **`Icon`**, `scripts/ui/icon.gd`, confirmed
  The vector icon set of the UI. Contract: `setup(kind, px, color = Palette.INK, accent = Palette.STAR) -> Control`; a change of `kind`, `color` or `accent` redraws it; it draws in a 100 x 100 box scaled to its size. The kinds are listed at the top of the file and in `_draw`; a new icon is a new `kind` branch there.
  Consumers: >=8 (JuicyButton, RangeBar and Screen preload it; defeat_card, hud, level_card, level_select_screen, result_card and toggle_row make it through them).
- **`JuicyButton`**, `scripts/ui/juicy_button.gd`, confirmed
  The candy button of the game UI: a lip style, a fast press, a spring release and the tap sound. Contract: `enum Kind { PRIMARY, SECONDARY, ROUND, ROW, CARD }`; `setup(kind, text, icon_kind = &"", height) -> Button` (centered icon and label) or `setup_custom(kind, height)` with the nodes of the caller in `content`; fields `label`, `icon_node`, `tap_sound` (false when the caller plays a different sound, as a locked card does); `shake()` for a refused tap. A press emits `Bus.ui_tap`. The content moves down with the lip on a press, so put custom content in `content`, not as a direct child.
  Consumers: >=9 (level_card and toggle_row extend it; Screen makes it for home_screen, level_select_screen, hud, pause_dialog, result_card and defeat_card).
- **`RangeBar`**, `scripts/ui/range_bar.gd`, confirmed
  The bar of the three star ranges of a level, with a marker at a move count. Contract: `setup(thresholds, result_mode)` with a thresholds dictionary of [[PRIMITIVES#ScoreRules]], `set_moves(moves, animate)`, `x_for(moves) -> float`. Meter mode (HUD) goes from 0 to the limit; result mode goes from the minimum to the limit, with a label for each range and a bubble with the moves. Each zone keeps a minimum share of the bar, so the scale is linear only inside one zone.
  Consumers: >=2 (hud, result_card).

## persistence

- **`Save`**, `autoload/save.gd`, confirmed
  Level progress and settings in `user://save.cfg`. Contract: `record(level_id, stars, moves, time_ms) -> {new_best}` (each field keeps its better value; a result with no star stores nothing), `best(level_id) -> {stars, best_moves, best_time_ms}`, `is_unlocked(index)` (level 0 always; level n when level n - 1 has one star or more), `highest_unlocked()`, `setting(key)` and `set_setting(key, value)` for the keys of `DEFAULT_SETTINGS` (emits `Bus.setting_changed`), `use_path(path)`, `unlock_all()` (memory only), `flush()`. Records use the level `id` as key, so a changed `id` in `levels_data.gd` loses its record; an unreadable file becomes `<name>.bad` and play continues with default data.
  Consumers: >=10 (Feel, Game, Harness, Music, Sfx, ui_lab, home_screen, level_card, level_select_screen, toggle_row).

## dev tooling

- **`Harness`**, `autoload/harness.gd`, confirmed
  Scripted runs from the command line: screenshots, scripted play, logs and a watchdog. Contract: arguments after `--` as `--key=value` or `--flag` (read in `_ready`, `_apply_setup` and `_plan`); `active()`, `has_arg(key)`, `arg(key, fallback)`, `shot(name)`, `mark(event)` (prints `HARNESS MARK`, takes the `--shot-on` shot, obeys `--quit-at`), `finish(code)`. It does nothing without arguments, stays silent in a `--script` tool run, reads the game only through the Game API and the Bus, and blocks real input during scripted play. The headless renderer draws nothing, so a screenshot run must be windowed.
  Consumers: >=5 (Game, Music, Sfx, board_lab, ui_lab).
- **`PerfPanel`**, `autoload/perf_panel.gd`, confirmed
  The in-game performance panel and the run sums for scripted performance checks. Contract: `toggle()` (also the `toggle_perf` action, F3, and a long press on the pause title), `is_open()`, `option(key)` and `set_option(key, value)` for `particles`, `glow` and `background` (saved in `user://perf.cfg`), signal `option_changed(key, value)`, `begin_run(log_over_ms)`, `run_summary() -> Dictionary`. Game applies the options (FxPool static switches, background decor). It measures only while it is open or while a run is on.
  Consumers: >=3 (Game, Harness, pause_dialog).
